# Human Test Checklist: choosing which tests run

**Target version:** 0.4.6
**Ships with commit:** v0.4.6: fix(tests): bring back run_tests.py categories over pytest markers
**Companion automated tests:** 99 passed, 13 skipped, 1 expected failure -- new: `tests/test_run_tests_driver.py` (9)

## What this is

`python tests/run_tests.py` had failed with an `ImportError` since June 2025. It now runs again, as a driver around pytest, with its old choices: unit, integration, GitHub (live) and deployment (live) tests, plus `--check` and `--keep-run`. This checklist covers what the suite cannot judge: how each run reads and how long it takes.

## Planning lineage

## Prerequisites

`pip install -e ".[dev]"`, run from the repository root. Nothing below needs signing turned off: the runner isolates every run.

## High-Value Verification (~5 minutes)

### HV.1 -- Unit tests alone, fast
- [ ] `python tests/run_tests.py --unit`
- [ ] **Expected:** about 60 passed, about 50 deselected, in a few seconds. No Kleopatra or GPG prompt.

### HV.2 -- Integration tests alone
- [ ] `python tests/run_tests.py --integration`
- [ ] **Expected:** about 40 passed and 1 xfailed, in a minute or two. No signing prompt; `~/.repokit/credentials.json` unchanged.

### HV.3 -- --check runs nothing and shows no secret
- [ ] `python tests/run_tests.py --check`
- [ ] **Expected:** lines for `.env.test`, the token's presence, Python, pytest and repokit. The token's **value** never appears. No tests run.

### HV.4 -- --keep-run keeps the repositories
- [ ] `python tests/run_tests.py --integration --keep-run -- -k legacy`
- [ ] **Expected:** "Test run directory (kept): ...\test_runs\test_run_<time>". The folder holds the generated `demo` repositories. `git status` stays clean, because `test_runs/` is git-ignored. Delete the folder yourself when done.

### HV.5 -- Live tests stay off unless asked
- [ ] `python tests/run_tests.py -- -rs` (no category)
- [ ] **Expected:** 12 live tests skipped, reported as two `SKIPPED [8]` / `SKIPPED [4]` lines reading "live GitHub test; set REPOKIT_LIVE_GITHUB=1 to run". **Do not** run `--github` or `--deployment` here unless you mean to create real GitHub repositories.

## What the automated tests DON'T cover

- How long each category takes on your machine (HV.1, HV.2).
- A real `--github` run: it creates repositories on the token's account, so it is never run automatically.
- Cleaning up `test_runs/`: the runner never deletes old runs.

## Cleanup

Delete any `test_runs/test_run_*` folders you kept.
