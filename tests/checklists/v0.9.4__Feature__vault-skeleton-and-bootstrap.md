## What this is

A created project's private vault now starts with the skeleton `/obsidian-init` used to lay by hand, and the part that needs a model is a prompt left for the oracle session. The tests prove the files, their tokens, the first commit's contents and the vendored library's purity. Only a person can judge whether the skeleton reads well in Obsidian and whether an oracle session can actually work from the prompt.
